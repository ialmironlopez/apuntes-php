# Apuntes de PHP básico

Repositorio personal con apuntes estructurados y explicaciones sencillas sobre los fundamentos de PHP, acompañados de ejemplos prácticos listos para ejecutar y practicar en un entorno local (XAMPP).

## Contenido

* **`php-basico/`**: Introducción al lenguaje, sintaxis, variables, tipos de datos, estructuras de control, operadores, arrays, funciones, manejo de errores y Programación Orientada a Objetos (POO).
